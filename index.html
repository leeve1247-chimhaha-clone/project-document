01

프로젝트 개요 및 목적

🎯
Why 침하하?
아마존·트위터보다 구현 난이도가 낮으면서도, 실제 프로덕션 단계에서 제대로 운영 중인 서비스라는 점에서 침하하를 선택했습니다. 단순 토이 프로젝트에 머물지 않고, 실제 서비스와 동일한 수준의 배포 환경 구성과 운영 이슈 경험을 목표로 합니다. 현재는 공개 운영 대신 로컬 환경에서 기능 검증 및 고도화를 진행 중입니다.
⚙️
로컬 서버를 선택한 이유
AWS의 온디맨드 과금 방식 대신, 한 번의 지출로 예측 가능한 비용을 유지하고자 미니 PC를 직접 서버로 운용합니다. Cloudflare Zero Trust Tunnel을 통해 인바운드 포트를 전혀 열지 않고도 외부 접속을 안전하게 처리합니다.
📸
주요 구현 화면
대문 페이지, 카테고리별 게시판, 로그인/회원가입, 게시글 및 댓글 CRUD, 이미지 첨부 기능을 모두 구현하여 실제 침하하 서비스의 핵심 UX를 재현했습니다.

주요 구현 기능

회원 인증 Keycloak
Keycloak 기반의 통합 인증 서버를 직접 구축하여 회원가입, 로그인, 소셜 로그인(네이버)을 처리합니다. Naver Keycloak Identity Provider를 커스텀 설치하여 소셜 연동을 구현했습니다.
게시글 · 댓글 CRUD
게시글 작성·수정·삭제, 댓글 작성·수정·삭제 기능을 구현했습니다. 권한 기반으로 본인 게시글 및 댓글만 수정·삭제 가능하도록 처리했습니다. ▶ 영상 보기
이미지 첨부 SeaweedFS
게시글에 이미지를 첨부할 수 있으며, SeaweedFS 객체 스토리지에 저장합니다. MinIO → SeaweedFS로의 스토리지 마이그레이션을 직접 수행했습니다. ▶ 영상 보기
카테고리 게시판
원본 서비스와 동일하게 여러 카테고리 구조의 게시판을 구현했습니다. 메인 페이지에서 카테고리별 최신 게시글을 동시에 조회하는 구조를 지원합니다.

문제 해결 경험

Trouble 01 · Keycloak
인증 서버 리다이렉트 무한 루프
Keycloak 관리자 콘솔에 브라우저로 접속했을 때 리다이렉트가 무한히 반복되는 문제가 발생했습니다. 컨테이너를 디버그 모드로 실행하여 원인을 추적한 결과, 리버스 프록시에서 포워딩하는 헤더 정보가 Keycloak의 기대값과 다른 것이 원인임을 파악했습니다.
해결
개발 환경(Nginx)에서는 X-Forwarded-For / Proto / Port 헤더를 명시적으로 추가하고, Keycloak 컨테이너 환경 변수에 KC_PROXY_HEADERS, KC_HOSTNAME을 설정하여 해결. 배포 환경(Cloudflare Zero Trust)에서는 해당 헤더를 기본 제공하여 프록시 설정 없이 Keycloak 권장 URI 규칙만 적용.
Trouble 02 · Storage
MinIO 라이선스 정책 변경에 따른 스토리지 마이그레이션
기존에 사용하던 MinIO의 오픈소스 진영에 적대적인 라이선스 변경을 확인하고 대안을 조사했습니다. GarageFS, Ceph, SeaweedFS, OpenMaxIO 네 가지 후보를 라이선스·단일 노드 지원 여부·S3 API 호환성·유지보수 활성도 측면에서 비교 분석했습니다.
해결
GarageFS는 버킷 정책 관련 문서 부족, Ceph는 미니 PC 환경에서 RAM 요구사항 과다, OpenMaxIO는 최근 업데이트 중단으로 제외. Apache 2.0 라이선스에 단일 노드부터 지원하는 SeaweedFS를 채택하여 마이그레이션 완료.
Trouble 03 · DevOps
개발 / 배포 환경 간 구성 괴리
오랜 기간 방치된 프로젝트를 재배포하는 과정에서 로컬 개발 환경과 실제 배포 환경 간의 설정 차이가 크게 벌어져 있었습니다. 단일 docker-compose.yml에 환경 변수(.env)만 교체하는 방식은 보안 설정, URL 스키마, 스토리지 구성 차이 등을 관리하기 어렵다는 한계가 드러났습니다.
해결
개발용과 배포용 docker-compose 파일을 각각 분리하고, IP·보안 비밀번호 등 환경별로 달라지는 배포용 설정 파일만 private submodule로 격리. 설정값 혼용으로 인한 오류를 방지하면서, 배포는 "로컬 빌드 → 산출물 복사 → 컨테이너 재실행" 3단계로 정립. 향후 CI/CD 파이프라인 도입으로 자동화 예정.
